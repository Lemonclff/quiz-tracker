## 🎮 遊戲介紹

### 玩法

學生扮演魔法學徒，從右側「魔法材料架」挑選等值配方，放入左側「魔藥瓶」中調配出指定濃度的魔藥。

```
┌──────────────────────────────────────────┐
│  🧙‍♂️ 「請調配濃度 0.5 的魔藥」            │
│  ═══════════════════ [時間條 ████░]      │
├────────────────────┬─────────────────────┤
│   🧪 魔藥瓶        │  📦 魔法材料架       │
│  ┌──────┬──────┐   │  ┌────┐┌────┐┌────┐ │
│  │ 50%  │ 1/2  │   │  │50% ││1/2 ││5%  │ │
│  │ 🧪   │ ⚗️   │   │  │🧪  ││⚗️  ││💧  │ │
│  └──────┴──────┘   │  └────┘└────┘└────┘ │
│                    │  ┌────┐┌────┐┌────┐ │
│  📘 魔藥筆記       │  │0.05││1/5 ││0.2 │ │
│  (15秒後自動出現)  │  │🧴  ││🫗  ││🧫  │ │
│                    │  └────┘└────┘└────┘ │
│  [🧹 倒掉重練]     │                     │
│                    │  [⚗️ 完成魔藥調配]   │
└────────────────────┴─────────────────────┘
```

### 關卡結構（對應小學數學課程）

| 關卡 | 難度 | 類型 | 題數 | 限時 | 通關門檻 | 密碼 | 對應年級 |
|------|------|------|------|------|---------|------|---------|
| 第 1 關 | 簡單 | 分數與小數互換 | 4 題 | 45 秒 | 60 分 | `potion101` | 四年級 |
| 第 2 關 | 中等 | 百分率與分數換算 | 4 題 | 50 秒 | 80 分 | `elixir202` | 五年級 |
| 第 3 關 | 困難 | 進階分數百分率 | 4 題 | 70 秒 | 100 分 | `grandmaster` | 五～六年級 |

**第 1 關題目**：`1/2` `1/4` `3/4` `1/5` — 基礎分數↔小數↔百分率互換

**第 2 關題目**：`0.3` `60%` `2/5` `0.15` — 百分率計算、約分、兩位小數

**第 3 關題目**：`1/8` `0.08` `1又2/5` `5/4` — 帶分數、假分數、非整數小數

### 計分規則

| 情境 | 分數變化 | 說明 |
|------|---------|------|
| 配方完全正確 | **+20** | 所有材料都選對 |
| 速度獎勵 | **+5** | 在獎勵秒數內完成（第1關10秒、第2關12秒、第3關20秒） |
| 配方錯誤 | **-20** | 放了不符合目標的材料 |
| 未放材料 | **-30** | 一個材料都沒放就提交 |
| 時間耗盡 | **-15** | 倒數結束仍未提交 |

### 稱號系統

| 魔力值 | 稱號 |
|--------|------|
| 1500+ | 🏆 魔藥大師 |
| 1101+ | 🥇 首席魔藥師 |
| 801+ | 🥈 傑出煉金師 |
| 601+ | 🥉 魔藥專精生 |
| 401+ | 📗 見習學生 |
| 201+ | 📘 魔藥新手 |
| 0+ | 📙 麻瓜 |

### 其他功能

- **倒數計時** — 每題獨立限時，時間條視覺化，超時自動提交
- **自動提示** — 設定秒數後「魔藥筆記」自動浮現（第1關15秒、第2關18秒、第3關22秒）
- **關卡密碼鎖** — 每關完成後需輸入導師密碼才能晉級
- **關卡重試** — 分數未達通關門檻時，可點「重新挑戰此關」重做，**保留之前累積分數**

## ⚡ 部署步驟（首次設定，約 5 分鐘）

### 步驟 1：建立 Google 試算表

1. 瀏覽器打開 **[sheets.new](https://sheets.new)**
2. 看到空白試算表，**不需要手動建立任何內容**
3. 記下這個試算表 — GAS 後端會自動建立所需的工作表和欄位

> GAS 部署後會自動建立兩個工作表：
> - `答題紀錄` — 22 欄逐題數據
> - `學生總分` — 自動彙整全班表現

### 步驟 2：部署 Google Apps Script 後端

#### 2a. 打開 Apps Script 編輯器

試算表上方選單 → **擴充功能** → **Apps Script**

#### 2b. 貼上後端程式碼

1. 在編輯器中**刪除所有預設文字**（全選 → Delete）
2. 打開本專案的 `game/concentration-lab.html`
3. 捲到**檔案最底部**，找到 `<!-- Google Apps Script 後端程式碼 -->` 註解區塊
4. 複製從 `// ---- 設定區 ----` 到 `GAS 程式碼結束` 之間的**所有程式碼**
5. 在 Apps Script 編輯器中貼上（Ctrl+V）
6. 點上方工具列 💾 **儲存**圖示

#### 2c. 部署為網頁應用程式

1. 點右上角藍色按鈕 **「部署」→「新增部署」**
2. 點左側齒輪 ⚙️ 圖示旁的下拉選單 → 選擇 **「網頁應用程式」**
3. 設定以下選項：
   - 描述：`魔藥煉成所 API`（可自訂）
   - **執行身分：我**
   - **誰可以存取：任何人**
4. 點 **「部署」** 按鈕
5. 跳出授權畫面 → 選擇你的 Google 帳號 → 點 **「允許」**
6. **複製畫面中央出現的網址**

> ⚠️ 這個網址格式為 `https://script.google.com/macros/s/XXXXX/exec`，**只會出現這一次**，請務必複製並保存！

#### 2d. 觸發首次授權（重要）

部署後，在 Apps Script 編輯器中：
1. 上方函式下拉選單選擇 `doGet`
2. 點 ▶️ **執行**按鈕
3. 若跳出授權視窗，依序點「審查權限」→ 選擇帳號 → 「允許」
4. 執行完畢後回到試算表，重新整理（F5）確認 `答題紀錄` 工作表已自動建立

> GAS 需要 `SpreadsheetApp` 和 `DriveApp` 兩個權限：前者寫入試算表，後者在 Google Drive 建立 JSON 備份檔案。

### 步驟 3：設定遊戲前端

1. 打開 `game/concentration-lab.html`
2. 搜尋 `WEB_APP_URL`（Ctrl+F）
3. 找到這一行（約在第 250 行）：
   ```javascript
   const WEB_APP_URL = "https://script.google.com/macros/s/...";
   ```
4. 把引號內的網址**替換成步驟 2c 複製的部署網址**
5. 儲存檔案

### 步驟 4：發佈遊戲給學生

#### 選項 A：GitHub Pages（推薦，永久免費）

```bash
cd quiz-tracker
git add game/concentration-lab.html
git commit -m "update WEB_APP_URL"
git push origin main
```

GitHub Pages 自動部署，1-2 分鐘後生效。學生打開：
```
https://lemonclff.github.io/quiz-tracker/game/concentration-lab.html
```

#### 選項 B：本地測試

直接在檔案總管雙擊 `concentration-lab.html`，用瀏覽器打開即可。本地模式會自動跳過 Google 傳輸（Console 顯示 `[測試]略過傳輸`），不影響試算表。

### 教師常用分析操作（直接在 Sheets 中進行）

**① 全班題型弱點分析**

選取 `答題紀錄` 全部資料 → 插入 → 樞紐分析表：
- 列：`levelType`
- 值：`isCorrect`（摘要方式：平均值 → 顯示正確率）、`timeTaken`（平均值 → 平均耗時）
- 篩選器：`difficulty`

→ 一眼看出哪個題型全班最弱、耗時最長

**② 個別學生診斷**

在 `答題紀錄` 中使用篩選器（Data → Create a filter）：
- 按 `studentId` 篩選 → 查看該生 `scoreChange` 趨勢、`timeTaken` 變化
- 找出該生在哪些題型反覆使用提示（`hintUsed=TRUE`）

**③ 耗時異常題目**

`答題紀錄` → 按 `timeTaken` 降冪排序 → 找出全班平均最慢的 3 題

**④ 分數分佈**

`學生總分` 工作表直接查看全班排名與分數分佈

**⑤ 提示有效性**

篩選 `hintUsed=TRUE` vs `hintUsed=FALSE`，分別計算 `isCorrect` 平均值，比較提示對正確率的影響

## 🎛️ 自訂關卡與題目

所有關卡設定集中在 `concentration-lab.html` 頂部的 `GAME_SETTING` 物件中。系統完全動態讀取——增加關卡或題目**不需修改任何程式碼**。

### 關卡級參數

```javascript
{
  levelNo: 1,              // 關卡編號
  difficulty: "簡單",       // 難度標籤（簡單/中等/困難）
  levelType: "分數與小數",  // 題型分類（用於試算表分析）
  nextLevelPassword: "xxx", // 本關通關密碼
  timeLimitSec: 45,         // 每題限時（秒）
  bonusTimeSec: 10,         // 在此秒數內完成可得速度獎勵
  bonusScore: 5,            // 速度獎勵分數
  baseScore: 20,            // 答對基礎分數
  wrongPenalty: -20,        // 配方錯誤扣分
  emptyPenalty: -30,        // 未放任何材料扣分
  timeoutPenalty: -15,      // 時間耗盡扣分
  hintAutoSec: 15,          // 幾秒後自動顯示提示（0 = 不出現）
  passScore: 60,            // 通關最低分數門檻
  questions: [ ... ]        // 題目陣列（見下方）
}
```

### 題目級參數

```javascript
{
  questionNo: 1,              // 題號
  target: "0.5",              // 目標值（內部比對用）
  targetDisplay: "0.5",       // 顯示在對話框的目標值
  slots: 2,                   // 魔藥瓶有幾個槽位（學生需選幾個材料）
  materials: [                // 材料架上的可選材料
    { label: "50%",  emoji: "🧪" },
    { label: "1/2",  emoji: "⚗️" },
    { label: "5%",   emoji: "💧" },    // 誘答：位置錯誤
    { label: "0.05", emoji: "🧴" },    // 誘答：小數點錯誤
    { label: "1/5",  emoji: "🫗" },    // 誘答：分子分母混淆
    { label: "0.2",  emoji: "🧫" }     // 誘答：1/5 的小數
  ],
  correctAnswers: ["50%", "1/2"],  // 所有等值配方（順序不拘）
  hint: "0.5 = 1/2 = 50%。\n\n小數：1 ÷ 2 = 0.5\n百分率：0.5 × 100 = 50%"
}
```

### 常見錯誤誘答設計建議

| 錯誤類型 | 範例（目標 0.5） | 學生常見迷思 |
|---------|-----------------|-------------|
| 小數點位置錯誤 | `0.05` | 搞混十分位和百分位 |
| 百分率單位混淆 | `5%` | 把小數直接當百分率 |
| 分子分母顛倒 | `2/1` | 不理解分數意義 |
| 未約分 | `5/10` | 忘記化簡分數 |
